# Random Number Generator

A simple JavaScript project that generates random numbers for practice and experimentation.

## Features

- Generates random numbers
- Uses browser-based JavaScript
- Simple, beginner-friendly code

## Getting Started

1. Clone or download this project.
2. Open the project folder in your code editor.
3. Open `index.html` in a web browser.

## Usage

Use the page controls to generate a random number. Adjust the project’s minimum and maximum values to change the range of possible results.

## Technologies

- HTML
- CSS
- JavaScript

## Learning Goals

This project demonstrates:

- Random number generation with `Math.random()`
- JavaScript functions and variables
- Responding to user interactions
- Updating a web page dynamically

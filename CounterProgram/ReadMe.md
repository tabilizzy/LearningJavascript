# Counter Program

A simple JavaScript counter application that lets users increase, decrease, or reset a numeric value.

## Features

- Increase the counter by one
- Decrease the counter by one
- Reset the counter to zero
- Instant updates in the browser

## Getting Started

1. Open `index.html` in a web browser.

Alternatively, run the folder with the Live Server extension in Visual Studio Code and navigate to the provided local address.

## Project Structure

- `index.html` — page markup
- `style.css` — application styling
- `index.js` — counter logic

## How It Works

The counter is stored in a JavaScript variable. Button clicks call functions that update the variable, and the page displays the current value through DOM manipulation.
